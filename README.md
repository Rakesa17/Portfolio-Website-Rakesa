# Personal Developer Portfolio

An interactive personal portfolio website showcasing modern web development projects, creative UI designs, and technical proficiency as a Frontend Developer, AI Engineer, and Web Designer.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
* **Core Roles:** Frontend Developer, AI Engineer, Web Designer
* **Tools:** Git, GitHub, VS Code

## Features
* **Interactive Interface:** Dynamic and engaging user navigation inspired by modern aesthetic concepts.
* **Project Showcase:** Highlights real-world repositories, live demos, and technical implementations.
* **Responsive Layout:** Fully optimized for seamless viewing across mobile and desktop devices.
* **Dynamic Time Display:** Real-time local browser clock integration for international accessibility.
